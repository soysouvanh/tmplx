  <h1>0-allocation content injection</h1>
  {% include "partials/card.html" %}
{% endblock %}
Tmplx compiler behavior

The directives extends, block and include are resolved statically at pure compile time.

Zero overhead: The complete HTML tree is unravelled then flattened in bytes directly into the Rust binary. No file lookup, and no partial array allocation happens at runtime. Inclusion literally costs 0 ms in production.

Installation & configuration (zero to hero)

1. Cargo Initialization

Add Tmplx to your Cargo.toml manifest.

Cargo.toml
[dependencies]
tmplx = "0.2.1"

[build-dependencies]
tmplx-compiler = "0.2.1"

2. The compiler (build.rs)

Place this file at the root of your project. It will parse your templates at compile time.

build.rs
fn main() {
    // Tells Cargo to re-build ONLY if the 'templates' directory changes.
    println!("cargo:rerun-if-changed=templates");

    // OUT_DIR is the hidden internal directory where the generated Rust code will be written.
    let out_dir = std::env::var("OUT_DIR").unwrap();
    let dest_path = std::path::PathBuf::from(out_dir).join("template_gen.rs");

    // Runs the Tmplx compiler. All HTML files become Rust macros.
    tmplx_compiler::build_workspace("templates", &dest_path);
}

3. Rust Usage

Your 100% statically typed macros are exposed! Zero file reading in production!

src/main.rs
// A. We load the magic code generated by our build.rs
pub mod generated {
    include!(concat!(env!("OUT_DIR"), "/template_gen.rs"));
}

// B. The "Duck-typing" struct required by the target page (e.g. for index.html)
struct MyViewData {
    title: String,
}

fn main() {
    // 1. Data initialization to render - my_view_data variable
    let my_view_data = MyViewData { title: "Tmplx".to_string() };

    // 2. Pre-allocation of the destination buffer (html_output). The engine will generate 0 allocations itself!
    let mut html_output = String::with_capacity(4096);

    // 3. Final call with the macro. Tmplx then pushes the variables and statics into 'html_output'.
    generated::render_index!(&mut html_output, &my_view_data);
}
